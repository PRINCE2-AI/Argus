01 — The boundary is the product

Small surface. Hard edges.

Argus is deliberately boring where it matters: one loop, one policy gate, one session format. The interesting parts are the edges.

01

Boundary-first tools

Every filesystem call resolves through a realpath jail. .env, .git, and .argus are blocked by name, not by convention.

02

Modes that mean something

read-only, safe, yolo. Safe asks. Headless runs deny instead of guessing. Deterministic deny patterns still apply in YOLO.

03

Sessions that survive

Append-only JSONL with torn-tail tolerance, interrupted-call repair, and compaction markers. Resuming is a first-class path, not an afterthought.

04

One loop, six providers

Gemini, Anthropic, OpenAI, OpenRouter, Groq, and Ollama. Tool IDs, thought signatures, and content blocks normalize at the edge.

05

Zero runtime dependencies

Python standard library only. Install it, read it, vendor it, or embed it. There is no framework underneath to learn or fight.

06

Tests without a model

A scripted provider drives the loop. The offline suite verifies safety, persistence, repair, and every adapter. CI covers Python 3.10–3.13.

02 — Provider neutral

Six providers.
One message format.

Tool-call IDs, Gemini thought signatures, Anthropic content blocks, and reasoning-model parameters stay at the edge. The loop never learns a vendor's dialect.

  • Provider-specific keys, base URLs, and model defaults
  • Usage normalized into input, output, and total tokens
  • Safety blocks and malformed responses raise clear errors
  • Ollama never inherits a cloud API key

03 — Safety as code

Three modes.
Zero ambiguity.

Approval is a code path, not a prompt instruction. Every tool call crosses the same Policy before it can touch the workspace.

  • Path jail — realpath confinement for every filesystem tool
  • Deny list — destructive shell semantics, independent of mode
  • Headless denial — no approver means no silent mutation
  • Fail closed — optional Jev review blocks when uncertain

Argus is not an OS sandbox. Run untrusted tasks in a container or VM.

05 — Durable sessions

The crash is the test.

Agent work is long-running and failure-prone. Argus appends each message as it happens, then earns the right to resume when the process disappears.

  • A torn final line is ignored, not fatal
  • Interrupted tool calls are paired and repaired
  • Old duplicate tool rows are removed on load
  • Compaction summaries are marked and restored
